Property list cleanup

Run either cleanup step

Upload your CSV or XLSX files once, then download either stage independently. The original uploads stay selected so you can run both buttons.

1. Choose your files

Multiple files are supported. Files are processed for the selected download and are not stored.

2. Download selected columns

Removes excluded columns, orders the requested fields, and downloads one processed CSV per input file.

3. Download Mobile/Wireless phones

Filters the phone columns to Mobile or Wireless, removes phone type columns, and downloads one CSV per input file.
